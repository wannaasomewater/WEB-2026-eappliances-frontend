# Electrical Appliances Frontend (Laboratory Work 5)

SPA на React + TypeScript для просмотра каталога электротехники. В проекте используются mock-данные (без бэкенда), реализована фильтрация по мощности, подстановка изображений по умолчанию и нижняя навигация.

## Стек технологий
- React 19 + TypeScript
- Vite
- React-Bootstrap + Bootstrap 5
- React Router DOM

## Установка и запуск

  npm install
  npm run dev

Приложение будет доступно по адресу http://localhost:5173.

## Страницы приложения

### 1. Лента (/)
- Отображает все товары в виде карточек (React-Bootstrap Card).
- На каждой карточке: изображение (или заглушка), название, мощность, частота, цена.
- Кнопка «Подробнее» (оранжевая, скруглённая).
- Адаптивная сетка: 1 колонка на мобильном, 2 на планшете, 3 на десктопе.
- Данные берутся из src/mockData.ts.

### 2. Плитка (/grid)
- Отображает товары в виде сетки.
- Фильтр по мощности: ползунок Form.Range от 0 до 3000 Вт с шагом 100.
- При движении ползунка список мгновенно фильтруется.
- Если ничего не найдено — выводится сообщение «Ничего не найдено».
- Реализация: useState (значение ползунка и отфильтрованный массив) + useEffect (пересчёт при изменении ползунка).

### 3. Добавление (/add) — заглушка
Доступ запрещён для гостя. Показывается сообщение «Эта страница находится в разработке».

### 4. Вход (/login) — заглушка
Доступ запрещён для гостя. Показывается сообщение «Эта страница находится в разработке».

## Навигация
Снизу зафиксирована панель BottomNav из 4 пунктов: Лента, Добавление, Плитка, Вход.
Для гостя доступны только «Лента» и «Плитка» (остальные ведут на заглушки).

## Изображение по умолчанию
Если в mock-объекте поле image пустое (''), в компоненте ApplianceCard срабатывает тернарный оператор и подставляется /assets/default-image.jpg из папки public/assets.
Для видео аналогично: если поле video пустое — рендерится картинка, иначе — тег video.

## Структура проекта

  src/
    components/
      ApplianceCard.tsx   # Карточка товара с обработкой заглушек
      BottomNav.tsx       # Нижняя навигационная панель
    pages/
      FeedPage.tsx        # Страница "Лента"
      GridPage.tsx        # Страница "Плитка" с фильтром
    mockData.ts           # Массив mock-объектов (электротехника)
    types.ts              # Интерфейс ElectricalAppliance
    App.tsx               # Роутинг и общая структура
    main.tsx              # Точка входа
    index.css             # Глобальные стили
  public/
    assets/
      default-image.jpg   # Заглушка для карточек
